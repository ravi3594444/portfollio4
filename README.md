## 🎨 Design

- Dark gradient background with parallax cosmic effects
- Glassmorphism navigation with backdrop blur
- Smooth scroll-reveal animations
- Typewriter effect for role display
- Premium typography: Syne (display) + Inter (body)
- Purple/blue gradient accents

---

## 📦 Setup

```bash
git clone https://github.com/ravi3594444/portfollio4.git
cd portfollio4
pnpm install
pnpm dev
```

## 🛠️ Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **TailwindCSS** with custom config
- **Vercel Analytics**
- **Material Symbols** icons
- **pnpm** package manager
